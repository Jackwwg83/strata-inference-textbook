先打个比方

一份稿子要经过 48 位编辑。如果每位编辑都把全文重抄一遍再改，抄到第 48 遍，原文早就走样了。更聪明的做法是：每人只在页边贴便利贴，写下自己的修改意见，原文一直保留。

Strata 跑的模型正是 48 层，每一层就是一位编辑。这一章拆开一层看：它读什么、算什么、怎样把结果“贴”回去；再看几处形状完全正确、意思却可能悄悄出错的接口。

一句话：一层分两半：先“混合历史”（36 层用 GDN，12 层用 QSA 注意力），再“专家加工”（MoE）。每一半都是“读残差 → 归一化 → 计算一个小修正 → 加回残差”。Strata 的残差不是一根向量，而是 4 条并行的车道。

7.1 一层在做什么：数进，数出

对模型来说，一个 token 在每一层之间就是一串数。Strata 用的模型里，这串数有 2560 个，叫隐藏向量。代码事实[S04] 每一层读进一串 2560 个数，吐出一串同样长的数，交给下一层。层与层之间传的，就是这串数里越来越丰富的“理解”。

神经网络的层与激活函数

直觉：一层神经网络像一排调音台。每个输出旋钮，都是把所有输入按不同比例混在一起。这一步就是第 3 章的矩阵乘法：输出 = 权重矩阵 × 输入。权重矩阵里的数，就是训练学出来的“参数”。

只有矩阵乘法还不够。两次矩阵乘法连起来，等于一次矩阵乘法：A(Bx) = (AB)x。叠 100 层也只相当于 1 层，学不出弯弯绕绕的规律。所以每次矩阵乘法之后，要过一个激活函数：一个逐个作用在每个数上的非线性函数，把直线“掰弯”。常见的三个如下，曲线见专栏后的图 7-2：

  • ReLU：负数变 0，正数不变。最简单。
  • sigmoid（σ）：σ(z) = 1 ÷ (1 + e−z)，把任何数压到 0 到 1 之间，所以常用来当“开关”或“门”：0 是关，1 是全开。
  • SiLU：SiLU(z) = z × σ(z)。它长得像平滑版的 ReLU，负数区域会微微下沉。

和本章的关系：Strata 的每一层里，sigmoid 和 SiLU 出现在不同的位置。它们的名字常被统称为“门”，但用错一个，数值就全变了，见 7.5 节。

延伸阅读：维基百科：人工神经网络 · 维基百科：激活函数 · 维基百科：S 型函数 · PyTorch 文档：SiLU

Strata 的 GDN 层里，激活函数的位置写得一清二楚：卷积之后对整段 10240 个数做 SiLU，然后才切成 q、k、v；写入强度 β 要先过 sigmoid；最后的输出乘的是 sigmoid(z)。代码事实（layer.hpp 第 10–22 行）这三处任何一处换个顺序、换个函数，结果都还是一串正常的数，只是错的。

7.2 48 层不是一个样：36 层 GDN + 12 层 QSA

每一层的前半段都要“回看历史”：当前 token 要从前文里找到相关信息。Strata 的模型准备了两种回看方式。QSA 是一种注意力：保留前文每个位置的记录，需要时挑出相关的去看（第 8 章）。GDN 则把前文压缩进一块固定大小的“白板”，每来一个 token 就擦写一次（第 9 章）。

哪一层用哪种，由一条规则决定：层号除以 4 余 3 的是 QSA，其余是 GDN。代码事实[S04] 层号从 0 开始数，所以 QSA 层是 3、7、11……47，共 12 层，其余 36 层是 GDN。见图 7-3。

不管前半段用哪种混合器，一层的骨架都一样。源码把一层的操作顺序写成两行 代码事实（layer.hpp 第 511–518 行）：

  • 前半层：读残差 → 混合器（GDN 或 QSA）→ 写回残差
  • 后半层：读残差 → MoE（第 10 章的专家）→ 写回残差

还有一个容易忽略的差别：QSA 层要知道当前 token 的位置，GDN 层根本没有位置参数。GDN 每个 token 的全部输入就是那串数，在 token 之间往前推进的，是它的白板状态。代码事实（layer.hpp 第 516–518 行）

7.3 归一化：先把音量调一致

数字在 48 层里一路加加减减，有的会越变越大，有的越变越小。如果不管，下一层的矩阵乘法一会儿收到“耳语”，一会儿收到“吼叫”，很难学好。所以几乎每次计算前，都要先把向量“调到标准音量”。

归一化：L2 与 RMS

归一化就是把一个向量除以它的“大小”，只保留方向。问题在于“大小”怎么量。两种常见量法只差一个除号：

  • L2 范数：‖x‖ = √(x₁² + x₂² + … + x_d²)，就是向量的几何长度。L2 归一化后，向量长度是 1。
  • 均方根（RMS）：√((x₁² + … + x_d²) ÷ d)，先求平方的平均再开根。RMS 归一化后，每个分量的“平均音量”是 1。

例子：x = [3, 4]。L2 长度是 √(9 + 16) = 5，归一化得 [0.6, 0.8]。RMS 是 √(25 ÷ 2) ≈ 3.54，归一化得约 [0.85, 1.13]。两种结果方向相同，大小差 √2 倍。一般地，d 维向量的两种结果相差 √d 倍。

实际公式里还有一个很小的数 ε（epsilon），加在根号里面，防止向量全是 0 时除以 0。RMSNorm 还会再乘一组学出来的系数，让每个分量可以有自己的音量。

和本章的关系：Strata 里两种都用，而且用在不同地方。用错一个，不会报错，只会差 √d 倍。

延伸阅读：Wikipedia: Normalization (machine learning) · RMSNorm 原始论文 · PyTorch 文档：RMSNorm · OI Wiki：向量

在 Strata 里：残差每次被读出时，每条车道各自做 RMS 归一化；GDN 层对 q 和 k 做的是 L2 归一化，v 不做。代码事实（gr.hpp 第 81 行；layer.hpp 第 12、23 行）GDN 的头文件专门提醒：ε 是加在平方和上的下限，不是加在平均数上，所以不能除以宽度；如果误读成“均方”，每个头 128 维，结果会差 √128 ≈ 11.3 倍。[S17] 这个模型的 RMS 归一化 ε 取 10−6。[S14][S18]

7.4 残差：每层只写“修改意见”

回到开头的编辑比喻。每层不重写这串数，只算出一个“修正”，再加回去。这条“原文一直保留、修正不断叠加”的通道，叫残差。

残差连接

残差连接把一层写成 x′ = x + f(x)：输出等于输入，加上这一层算出的修正 f(x)。如果某一层“没什么可改”，它只要让 f(x) 接近 0，输入就原样通过。

为什么这很重要？没有残差时，信息要穿过每一层的矩阵乘法和激活函数，层数一多，原始信号就像传话游戏一样走样；训练时，误差信号往回传也会越来越弱。有了残差，就多了一条“直通车道”：第 1 层的信息可以几乎原样到达第 48 层，误差信号也能沿着这条车道传回来。2015 年的 ResNet 用这个想法，把图像网络稳定地训练到了上百层。

现代语言模型通常写成 x′ = x + f(norm(x))：先归一化，再计算，再加回原来的 x。注意加回去的是没归一化的 x。

和本章的关系：Strata 的模型把这条直通车道扩成了 4 条，加回去时还带着可学习的权重。

延伸阅读：维基百科：残差神经网络 · ResNet 原始论文 · The Illustrated Transformer（图解，含残差与归一化）

Strata 的残差是 4 条并行的车道，每条 2560 个数。代码事实[S04][S13] 读的时候，4 条车道各自归一化，再合成一个向量交给混合器或 MoE；写回的时候，同一个修正加到每一条车道上，只是每条车道乘的权重不同。权重是 w = 2 × sigmoid(inject ÷ 4)，其中 inject 是读残差时顺便算出的一个数。（gr.hpp 第 6–8、114–120 行）

这个“2 倍 sigmoid”的设计很巧：sigmoid(0) = 0.5，所以 inject = 0 时 w 正好是 1，写回就退化成普通的残差相加。源码注释也特别指出了这一点，测试里还专门断言了它。权重可以在 0 到 2 之间变化，让模型自己决定每条车道“多听一点”还是“少听一点”。见图 7-4。

学过计算机的同学：残差连接有点像版本控制里的“补丁”：每层提交一个 diff，而不是重写整个文件。48 个补丁依次打上去，原始内容始终在。代价是：任何一层的补丁打错了，错误也会沿着这条直通车道一路传到最后，不会被“冲淡”。

7.5 形状对了，意思也要对：模块契约

一层由十几个小步骤组成，每个步骤单独测试都对，拼起来仍可能错。最危险的错误，是那些形状完全正确、数值完全正常的错误：不崩溃，不出 NaN，只是悄悄算出另一个答案。Strata 的源码里记着好几处这样的“契约”，图 7-6 挑了四个。

  • β 要先过 sigmoid，而且由层负责。GDN 的单步内核不做这一步，它的契约是“收到的 β 已经是 0 到 1 之间的分数”。头文件用大写写着：内核不做，层必须做。[S17]
  • 输出门是 sigmoid，不是 SiLU。qwen3.5 模型在这里用 SiLU，这个模型不是。[S17] 两个函数的名字都和“门”有关，形状一样，数值完全不同。
  • 路由权重只乘一次。专家池不乘路由权重，乘权重由显卡上的合并步骤统一完成。如果两边都乘，单看一层几乎发现不了，叠加 48 层后误差越滚越大。[S06]
  • 专家输出要配本层的权重。为了让 CPU 算专家和 GPU 干活同时进行，早期版本把第 l 层的专家结果交给第 l+1 层去合并，于是用了第 l+1 层的权重。注释称它产出的是“一个有限、流畅、确定，但不属于这个模型的 token”。修复办法是把一层拆成两段图：路由完先让 CPU 算，算完再用本层的权重合并。代码事实（layer.hpp 第 146–165、177–179 行）

学过计算机的同学：这是《软件工程》里“接口契约”和“集成测试”的活教材。每个函数的单元测试都通过，不代表组合起来对。契约要写清楚“谁负责做什么”（谁过 sigmoid、谁乘权重），集成测试要拿整层、整个 token 的输出去和参考实现比。

7.6 动手：看一层怎样读、算、写

本章没有独立的实验页，两个交互图就是实验：

  1. 在「走一遍一层」里，从第 0 层连按 6 次单步，观察车道上的数每次只变一点点；再把起始层拉到 3，确认混合器换成了 QSA；最后把车道 0 的注入值拉到 0，验证写回权重正好是 1。
  2. 在「L2 vs RMS」里，依次点 [3, 4] 和 128 维，记下两次的比值，验证它等于 √d。

纸笔练习：两个专家的输出是 [2, 0] 和 [0, 4]，路由权重是 0.25 和 0.75。正确的合并结果是 0.25 × [2, 0] + 0.75 × [0, 4] = [0.5, 3]。如果专家池已经乘过一次权重，合并时又乘一次，结果会是多少？为什么这种错误很难靠“看输出是否正常”发现？

记住这三点

  1. 一层 = 两个半层：读残差 → 混合器（36 层 GDN，12 层 QSA，规则是层号 % 4 == 3 为 QSA）→ 写回；读残差 → MoE → 写回。
  2. 归一化把向量调到标准大小。L2 除以平方和的根，RMS 除以平方平均的根，二者差 √d 倍；GDN 的 q、k 用 L2，用错会差 11.3 倍。
  3. 残差让每层只写“修正”。Strata 的残差有 4 条车道，写回权重 w = 2 × sigmoid(inject ÷ 4)，inject = 0 时就是普通相加。

常见误解：“每个算子都测过了，拼起来的层就一定对。”

算子各自正确，拼的时候仍可能传错层、少过一次 sigmoid、多乘一次权重、用错归一化的分母。这些错误都产出正常的数字，单元测试看不见。必须拿整层、整个 token 的输出和参考实现对比，才能抓住它们。

深入一层：多车道残差的真实公式、按类型选激活格式、怎样定位是哪一层错了

教学式 x′ = x + f(norm(x)) 不是 Strata 的逐项等式

本章正文用单向量的残差公式建立直觉。真实的模型几何里有 hc = 4，会话状态里的残差 R 是 4 × 2560 的多车道结构。[S04][S13] 把它换成普通的单向量残差，模型就变了。

读残差（gr_read）的完整步骤是：每条车道各自做 RMS 归一化得到 xn（归一化系数在存储时就写成了 1 + w 的形式）；把 4 条车道拼起来，经过一个 320 维的“瓶颈”：lo = SiLU((xn 的 BF16 版本 × w_down) ÷ hc)；注意除以 hc 是在 SiLU 里面，很容易看漏，而且会实质改变结果。然后 mixed = 各车道上 xn × sigmoid(lo × w_up) 的平均；inject = xn × w_inject。最后一层之后的“最终混合”没有 inject，因为后面没有写回了。（gr.hpp 第 79–91 行）

写回（gr_write）是 R_out[c] = R[c] + block_out × w[c]，w[c] = 2 × sigmoid(inject[c] ÷ hc)。（gr.hpp 第 114–120 行）

这些车道权重都是 BF16 格式。打包文件为了解码简单，把它们放大成 32 位存储；引擎加载时再收回 16 位，不损失任何精度，却省下 5.305 GiB 稠密权重中的 1.374 GiB。注释说，这正是“稠密权重能和专家缓存一起放进显存”与“放不下”的区别。（gr.hpp 第 10–14 行）

激活格式跟着张量类型走，不跟着名字走

量化权重在做矩阵乘法前，要把输入向量也转换成匹配的格式。layer.cpp 记录了一个教训：同一个名字的张量，在不同层用的量化类型可能不同。比如 36 个 GDN 层的 attn_qkv，有 13 层是 IQ4_XS、18 层是 Q3_K、4 层是 Q4_K、1 层是 Q2_0。规则是按类型定的：2 位编码配 Q8_0 格式的输入，其他量化类型配 Q8_K。选错格式会让矩阵乘法偏差 0.6%–1.4%，得到的是一个“看起来合理”的向量，而不是坏掉的向量。[S14]

怎样知道是哪一层、哪一步错了

Strata 准备了两级“对账单”。逐层的残差记录（residual ladder）告诉你从哪一层开始和参考实现分道扬镳；半层级的记录再把每层拆成“注意力半层的输出”“MoE 半层的输出”和两组 inject，告诉你是哪一步。这些拷贝本身被录进每层的 CUDA 图里，随层一起重放；不开启时没有任何开销。（layer.hpp 第 448–456 行）

还有一个调试开关 --sync-every-layer：每层之后插一次同步和错误检查。它能抓住“某个内核读了一块后面的层才会写的缓冲区”这类错误，平时看不见；代价是正好违反了快速路径“不许同步”的要求，所以它是运行时参数，而不是默认行为。[S13]

为什么组合测试必不可少

模块之间可能传错层的激活、重复归一化、重复加权、用错布局或错的状态。每一种都能通过各自的单元测试。正确的做法是：固定输入和历史，拿整层输出、半层输出这些中间检查点，去和独立的参考实现逐项比较。只比最后一个 token 对不对，往往太晚，也太粗。
