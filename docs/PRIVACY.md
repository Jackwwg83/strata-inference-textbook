# 隐私说明

本站记录**匿名**访问统计，用来了解哪些章节有人读、读者在哪一章离开，从而改进教材。

## 记录什么

每次你打开一个页面、把一章标记为学完、或核对一道自测题时，浏览器向本站的 `/api/collect` 发送一条事件。服务器保存：

| 字段 | 例子 | 来源 |
| --- | --- | --- |
| 时间 | 2026-10-04 16:00 | 服务器时钟 |
| 事件类型 | 浏览 / 学完 / 答题（对或错） | 页面 |
| 页面 | `chapter/17`、`lab/spec` | 页面地址 |
| 来源站点 | `www.zhihu.com`（只存域名） | 浏览器的 referrer |
| 国家、地区、城市 | CN / SH / 上海 | Vercel 边缘节点的地理信息 |
| 设备、浏览器类型 | 手机 / Safari | User-Agent 归类后的结果 |
| 浏览器语言 | zh-CN | 页面 |
| 访客标识 | 16 位十六进制 | 见下文 |

## 不记录什么

1. 不保存 IP 地址。
2. 不设置 cookie，不使用指纹库。
3. 不收集笔记、书签、实验参数或答题内容；“答题”事件只记录对错。
4. 不与任何第三方共享数据，不接入第三方统计或广告服务。

## 访客标识

服务器把“密钥 + 当天日期（UTC）+ IP + User-Agent”做 SHA-256 哈希，取前 16 位作为当天的访客标识。IP 只参与计算，不落库。日期每天变化，所以同一个人在不同日期的记录无法互相关联，也无法从标识反推 IP。

## 不被统计的情况

- 浏览器开启了“请勿追踪”（Do Not Track）或全局隐私控制（GPC）。
- 爬虫、无头浏览器和脚本请求。
- 在本机 `localhost` 或直接打开文件阅读。

## 数据存放

事件存放在 Neon Postgres（经 Vercel Marketplace 开通），只有站点作者能通过口令保护的 `/admin` 页面查看汇总。如需删除或有疑问，请在 GitHub Issues 提出：https://github.com/Jackwwg83/strata-inference-textbook/issues
