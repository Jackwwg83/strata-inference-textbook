## 浏览器环境限制：必须与结果一起阅读

本环境 Chromium 的管理员策略禁止所有 URL 导航，包括 localhost 与 file://。测试没有修改该策略，而是使用 Playwright `page.set_content` 将本地构建 HTML 放入浏览器执行。

这允许验证真实 DOM、CSS、JavaScript 与表单/文件读取交互。由于该页面没有正常 HTTP origin，本轮持久化使用了明确的内存 localStorage 测试替身，验证序列化、初始化恢复与路由切换状态；另外测试真实存储不可用时页面显示警告。

因此，**不能把本轮结果称为真实浏览器磁盘持久化、原生下载投递或 Vercel 上线的完整端到端验收**。导出检查截获 Blob 并核验 HTML/JSON 内容，不声称操作系统下载目录实际收到文件。HTTP 静态服务由独立请求测试验证。

`tests/browser_qa.py` 支持在正常环境下使用 `--url http://127.0.0.1:3000/`，此时用原生 localStorage；`--render-only` 才显式启用本次的替身方式。测试记录见 `browser-qa.json`。
